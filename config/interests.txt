Chúng tôi là công ty làm theme bán trên Shopify Theme Store. Radar tập trung vào THEME:
những gì làm thay đổi cách theme được xây, duyệt, bán hoặc chạy trên store của merchant.
Xếp theo thứ tự ưu tiên:

1. Thay đổi nền tảng ảnh hưởng tới theme, nhất là có hạn chót: Liquid (tag, filter, object mới hoặc bị ngừng hỗ trợ), cấu trúc theme, Online Store 2.0, JSON template, section, block, theme block, settings schema, metafield và metaobject dùng trong theme, Section Rendering API, Ajax/Cart API.
2. Yêu cầu duyệt của Theme Store, chính sách dành cho người bán theme, tiêu chí hiệu năng và accessibility (Lighthouse, Core Web Vitals).
3. Theme editor: tính năng mới, thay đổi cách merchant chỉnh theme, lỗi và độ chậm của editor.
4. Theme mặc định và theme tham chiếu của Shopify (Dawn, Horizon…), Shopify CLI cho theme, Theme Check, công cụ dev theme.
5. Hiệu năng theme: tốc độ trang, ảnh, script, số section lớn.
6. Merchant cần gì ở theme mà theme hiện tại chưa có (bundles, quick add, mega menu, bộ lọc, swatch, nhiều SKU…), phàn nàn và so sánh theme.
7. App ảnh hưởng tới theme: app block, theme app extension không hiển thị, xung đột script hoặc CSS với theme.
8. Nội dung trong Shopify Editions liên quan tới theme hoặc theme editor.

Bỏ qua: thay đổi chỉ dành cho app (Admin API, GraphQL cho app, Shopify Functions, Polaris, App Bridge, billing app, checkout UI extensions không đụng tới theme), tin tuyển dụng, quảng cáo dịch vụ, bài bán hàng, dropshipping chung chung.
