Chúng tôi là công ty làm theme bán trên Shopify Theme Store. Radar tập trung vào THEME, nhìn từ ba phía:

- Theme (code): những gì làm theme phải sửa code, hoặc có thể dùng để làm tính năng mới.
- Partner (nhà bán theme trên Theme Store): quy trình duyệt, yêu cầu và chính sách Theme Store, listing, review, doanh thu và chia sẻ doanh thu, Partner Program, Partner Dashboard, hỗ trợ khách mua theme.
- Merchant (người dùng theme): theme editor, tính năng merchant cần, cách merchant chỉnh và dùng theme, phàn nàn và so sánh theme.

Xếp theo thứ tự ưu tiên:

1. Thay đổi nền tảng ảnh hưởng tới theme, nhất là có hạn chót: Liquid (tag, filter, object mới hoặc bị ngừng hỗ trợ), cấu trúc theme, Online Store 2.0, JSON template, section, block, theme block, settings schema, metafield và metaobject dùng trong theme, và các API theme gọi từ trình duyệt: Ajax API (Cart API /cart/add.js, /cart/change.js, /cart/update.js, Product API, Predictive Search API, Product Recommendations API) và Section Rendering API.
2. Theme Store và Partner: yêu cầu duyệt, tiêu chí hiệu năng và accessibility (Lighthouse, Core Web Vitals), chính sách và điều khoản cho người bán theme, listing, review, doanh thu, Partner Program.
3. Theme editor: tính năng mới, thay đổi cách merchant chỉnh theme, lỗi và độ chậm của editor.
4. Theme mặc định và theme tham chiếu của Shopify (Dawn, Horizon…), Shopify CLI cho theme, Theme Check, công cụ dev theme.
5. Hiệu năng theme: tốc độ trang, ảnh, script, số section lớn.
6. Merchant cần gì ở theme mà theme hiện tại chưa có (bundles, quick add, mega menu, bộ lọc, swatch, nhiều SKU…), phàn nàn và so sánh theme.
7. App ảnh hưởng tới theme: app block, theme app extension không hiển thị, xung đột script hoặc CSS với theme.
8. Storefront API, chỉ phần chạm tới theme: theme gọi Storefront API từ JavaScript (public access token), hoặc thay đổi về dữ liệu theme cũng hiển thị (metafield/metaobject public, giá theo thị trường, selling plan, tồn kho).
9. Nội dung trong Shopify Editions liên quan tới theme, Theme Store hoặc theme editor.

Bỏ qua:
- Thay đổi chỉ dành cho app: Admin API, GraphQL cho app, Shopify Functions, Polaris, App Bridge, billing app, webhook, checkout UI extensions không đụng tới theme, App Store.
- Headless: Hydrogen, Oxygen, Storefront API cho site tự dựng, Customer Account API cho headless.
- Tin tuyển dụng, quảng cáo dịch vụ, bài bán hàng, dropshipping chung chung.
